AthenaPK 3D Static-Mesh Wave Studies
====================================

This report contains two statically refined convergence studies: the configured
linear MHD wave families and the circularly polarized traveling Alfvén wave
(CPAW). Each problem is divided into separate CT-MHD and GLM-MHD sections, with
problem-specific convergence tables and MeshBlock visualizations.

All reported L1 errors are volume-weighted so coarse and refined regions contribute
in proportion to their physical volume.
